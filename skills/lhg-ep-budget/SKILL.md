# lhg-ep-budget：活动预算编制

## 何时使用

- 活动目标定下来后，需要把"要花多少钱"算清楚时。
- 拿到一个预算上限，需要判断"这个钱够不够办、怎么分配"时。
- 活动结束后复盘"钱花哪了、哪里超了"时（配合 lhg-ep-postmortem）。

不适用：纯线上、零成本的内部小会（10 人以内、无外部支出）——口头对一下即可，不用走全套。

## 输入与输出

**输入**：活动类型、规模（人数/天数）、预算上限（可选）、已知的硬性支出（如场地已询价）。

**输出**：预算表（Markdown 表格）+ 取舍说明 + 支付节点计划。预算表每行：类目 / 明细项 / 金额 / 负责人 / 支付节点 / 备注。

## 分步方法论

### 第 1 步：按七大类目拆解

所有活动支出先归入七类，归不进去的单独列"其他"并说明理由：

| 类目 | 包含 | 常见坑 |
|---|---|---|
| 场地 | 租金、押金、超时费、清洁费 | 只问租金不问超时费和清洁费 |
| 搭建 | 舞台、灯光音响、LED 屏、桌椅租赁 | 搭建超时的人工费、运输费漏算 |
| 餐饮 | 茶歇、正餐、外卖、饮用水 | 人数按"到场"还是"邀约"算 |
| 物料 | 印刷品、伴手礼、签到物料、服装 | 打样费、加急费、损耗（多备 5%） |
| 嘉宾 | 差旅、住宿、讲课费/出场费、接送 | 发票抬头、税费谁承担 |
| 传播 | 摄影摄像、直播、媒体车马费、投流 | 成片交付时间写进合同 |
| 应急 | 不可预见费，默认 10% | 第一个被挪用的就是它 |

### 第 2 步：询价与估算分级

每个明细项标注信息等级：

- **已询价**：有供应商书面报价，写报价有效期。
- **参照估算**：按历史活动或市场价估算，写参照来源。
- **拍脑袋**：实在没依据，写"待询价"并标为风险项，48 小时内必须落实。

"拍脑袋"项超过总预算 30% 时，预算表整体不可信，先去做询价再往下走。

### 第 3 步：应急预留 10%

应急预留是单独一行，不许拆分到各明细里"消化"掉。动用应急预留需要负责人签字（哪怕只是口头确认并记录）。活动类型风险越高（户外、大型、首次办），预留提到 15%。

### 第 4 步：支付节点计划

每笔支出写清"什么时候付、付多少、付给谁"：

```
场地租金 20000 元：签约付 50%（11-01），活动结束验收后付 50%（12-21）
```

现金流断裂是小团队办活动翻车的主因之一：钱不是不够，是到的时间不对。

### 第 5 步：求和校验与取舍

- 分项求和必须等于总预算，差一分钱都要说明（凑整项单独列一行"凑整"）。
- 预算上限不够时，按"目标相关度"砍：先砍与核心目的无关的"面子项"（如过贵的伴手礼），再砍可降级的（如 LED 屏换投影），最后才动核心体验项。每次砍都要写取舍理由，形成记录。

## 反模式

- **漏项预算**：只算大头不算零碎（运输、加急、税费、损耗），零碎加起来经常超 15%。
- **人均成本失控**：总预算 ÷ 到场人数 = 人均成本。发布会人均超过 500 元、团建人均超过 800 元时，停下来重新审一遍"值不值"。
- **预算=报销单**：预算表做完就扔，实际花费不对照——预算必须和复盘挂钩。
- **口头报价**：供应商口头说"大概 2 万"，最后开票 2 万 8——2 万以上的项必须书面确认。
- **应急预留被挪用**：一开始就把 10% 分摊到各明细里，等于没有应急。

## 完整示例：10 万元 200 人发布会预算表

| 类目 | 明细项 | 金额 | 负责人 | 支付节点 | 备注 |
|---|---|---|---|---|---|
| 场地 | 酒店宴会厅半天 | 30000元 | 小王 | 签约付50%，结束验收后付50% | 已询价，有效期至 11-30 |
| 搭建 | 舞台+灯光音响+LED | 25000元 | 小李 | 搭建前付全款 | 含运输费 2000元 |
| 餐饮 | 茶歇 200 人份 | 12000元 | 小张 | 活动前三天付全款 | 按到场 200 人计，邀约 260 人 |
| 物料 | 伴手礼+印刷品 | 8000元 | 小李 | 下单付50%，到货付50% | 伴手礼降档版，见取舍说明 |
| 嘉宾 | 2 位嘉宾差旅 | 10000元 | 小王 | 按实际报销支付 | 发票抬头已确认 |
| 传播 | 摄影摄像+直播 | 5000元 | 小张 | 交付成片后付全款 | 成片 7 天内交付写进合同 |
| 应急预留 | 不可预见费 10% | 10000元 | 总负责人 | 动用需签字确认 | 不许拆分消化 |
| 合计 | | 100000元 | | | 分项求和=合计，已校验 |

预计到场 200 人，人均成本 500 元。

**取舍说明**（预算上限 10 万倒逼）：原伴手礼方案 15000 元（定制礼盒）→ 降为 8000 元（品牌帆布袋+产品小样）。理由：本次活动类型为品牌曝光型，传播物料（摄影/直播）与核心目的更相关，伴手礼属于"面子项"，优先保传播。

## 砍预算的优先级清单

预算不够时，按这个顺序砍，每砍一刀都写理由：

1. **先砍面子项**：过贵的伴手礼、开场表演、鲜花布置——与核心目的无关。
2. **再砍可降级项**：LED 屏换投影、定制物料换通用版、 hot 餐饮换茶歇——体验降一档但不断档。
3. **三砍传播外包**：摄影从双机位变单机位、直播从多平台变单平台——能自己干的先自己干。
4. **最后才动核心体验**：签约区的布置、嘉宾的接待标准——动了这些，活动目的就保不住了。
5. **绝不动应急预留**：砍到应急预留头上时，说明预算根本不够，要么缩小规模，要么申请追加。

## 询价话术要点

- 永远问三家：最低价不是目标，问出"市场价区间"才是目标。
- 问清"全包价"：运输、安装、超时、税费、损耗，五个附加项逐项问。
- 2 万元以上的项：书面报价（邮件/微信文字确认均可），口头报价一律视为"待询价"。
- 付款方式写进预算表备注：供应商要求"全款预付"时，标为风险项（跑路风险+议价权丧失）。

## 应急预留动用流程

应急预留不是"小金库"，动用走三步：

1. **申请**：经办人说明"什么事、要多少钱、为什么原预算覆盖不了"，口头/文字均可，但必须留记录。
2. **审批**：总负责人确认"这事值不值得动应急"，签字（微信回复"同意"截图亦可）。
3. **记账**：动用后更新预算表，写清"X 月 X 日动用 XXXX 元用于 XXX，剩余 XXXX 元"。

活动结束后，应急预留有结余是好事，写进复盘报告"预算复盘"部分；全部用光甚至不够，说明当初的风险评估偏乐观，下次提高预留比例或缩小规模。

## 一句话速查

- 询价分三级：已询价（写有效期）/ 参照估算（写来源）/ 拍脑袋（标待询价，48 小时落实）。
- 拍脑袋项超总预算 30% → 整表不可信，先询价再往下走。
- 人均成本 = 总预算 ÷ 到场人数，发布会超 500 元、团建超 800 元要重审。
- 大额支出（2 万以上）必须书面确认，口头报价=待询价。
- 预算表是复盘的对照组：做完就扔，等于没做。

## 自检与反馈

**质检门**（输出前自查）：

- [ ] 七大类目全覆盖，无"其他"类目超过总预算 10%
- [ ] 应急预留单独成行，比例 ≥10%（高风险活动 ≥15%）
- [ ] 分项求和 = 总预算（含"凑整"行说明）
- [ ] 每个明细项有负责人与支付节点
- [ ] "拍脑袋"项合计 ≤ 总预算 30%，且每项标注了落实期限
- [ ] 人均成本已计算并在合理区间

**标准冒烟用例**：输入"200 人线下发布会，预算上限 10 万"，应输出七类目预算表、应急 1 万单独成行、分项求和=10 万、每项有负责人与支付节点，并给出"预算不够时先砍伴手礼档次"的取舍建议。

**一键反馈**：发现方法论缺口，以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-event-plan/issues，正文写清"场景 → 当前方法的不足 → 期望补充什么"。
