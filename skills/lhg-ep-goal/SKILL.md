# lhg-ep-goal：活动目标拆解

## 何时使用

- 用户只说了一句话（"搞个发布会""办场团建""做个路演"），你需要把它变成可执行的方案起点时。
- 活动方案已经写了一半，但你发现"到底要达成什么"说不清楚时——先回这一步，别往下写。
- 复盘时发现"当时目标就没定清楚"，下次开工前用这套方法先定目标。

不适用：目标已经量化且各方对齐（比如"双11大促 GMV 目标 500 万，去年 420 万"）——直接进入预算环节。

## 输入与输出

**输入**：用户的一句话描述 + 可选的背景（预算范围、日期、人数量级）。

**输出**：一份"目标说明书"，包含：活动类型判定、目标人群画像、核心目的（单选）、3~5 个量化指标（每个带衡量口径与数据来源）。

## 分步方法论

### 第 1 步：判定活动类型

先给活动定型，不同类型的成功标准完全不同：

| 类型 | 典型例子 | 成功长什么样 |
|---|---|---|
| 品牌曝光型 | 发布会、快闪、品牌日 | 传播量、媒体报道数、社交声量 |
| 获客转化型 | 路演、体验日、招商会 | 线索数、转化率、签约额 |
| 关系维护型 | 答谢宴、团建、行业闭门会 | 到场率、满意度、二次邀约率 |
| 销售促成型 | 订货会、品鉴会、直播专场 | 当场订单额、客单价、复购意向 |

定错了类型，后面所有指标都会跑偏。拿不准就问用户一个问题："活动结束那天晚上，你希望发生的最重要的事是什么？"答案指向哪类，就是哪类。

### 第 2 步：画目标人群画像

写清楚三件事：**谁来**（身份/职位/地域）、**为什么来**（他能得到什么）、**来了之后希望他做什么**（下一步行动）。人群画像越具体，邀约文案和场地选择越有依据。

反例："面向广大消费者"。正例："25~35 岁一线城市女性，新品尝鲜意愿强，希望她们现场扫码领券并 7 天内下单"。

### 第 3 步：核心目的单选

一个活动只能有一个核心目的。获客和品牌都想要 = 都要不到。让用户做选择题：

> 如果只能实现一个，A 到场 500 人但没人下单，B 到场 100 人但签了 30 单，你选哪个？

选 A 是品牌/获客型，选 B 是转化型。次要目的可以写，但预算和人力分配必须向核心目的倾斜。

### 第 4 步：定 3~5 个量化指标

每个指标必须过"三问"：

1. **可衡量吗？**——"提升品牌影响力"不行，"活动后 7 天品牌词搜索量提升 20%"可以。
2. **可归因吗？**——指标变化能对应到这次活动吗？"当月销售额"不行（混杂因素太多），"活动现场扫码领取的优惠券核销数"可以。
3. **有数据来源吗？**——谁来数、用什么工具数、什么时候数，三个都定下来才算数。

指标模板（每个指标一行）：

```
指标：现场签约额
口径：活动当天 18:00 前签署的意向书金额总和（不含口头承诺）
目标值：≥ 80 万元
数据来源：销售负责人当晚 20:00 前汇总
```

### 第 5 步：写目标说明书并对齐

把以上四步合并成一页纸，发给所有干系人确认。目标说明书是后续所有决策的"宪法"：预算不够砍哪项、嘉宾请谁、场地选哪，全部回来看目标。

## 反模式

- **指标通胀**：列了 12 个指标，等于没有指标。超过 5 个就逼用户砍。
- **虚荣指标**：到场人数 2000 但目标人群只占 10%——人数好看，目的落空。
- **事后指标**：活动结束才想起来定指标，复盘时只能写"感觉不错"。
- **老板指标**：指标是"让老板满意"——翻译成可衡量的：老板满意 = 他在朋友圈转发了 + 当场介绍了 3 个客户。
- **模糊动词**：目标里出现"提升""加强""促进"且无数字，直接打回。

## 完整示例：经销商订货会

用户输入："下个月给经销商办场新品订货会，来的大概 150 家。"

**第 1 步判定类型**：销售促成型。成功 = 现场签约，不追求传播声量。

**第 2 步人群画像**：

- 谁来：现有经销商 120 家 + 意向经销商 30 家，到场人是老板本人或采购负责人
- 为什么来：看新品实物、拿首批订货政策、跟其他经销商交流行情
- 来了做什么：现场签意向书、交定金锁定政策

**第 3 步核心目的单选**：问用户"150 家都来但 0 签约 vs 80 家来但签 60 单"，用户选后者 → 核心目的 = 现场签约额，次要目的 = 新经销商拓展。

**第 4 步量化指标**：

```
指标：现场签约额
口径：活动当天 18:00 前签署的意向书金额总和（不含口头承诺）
目标值：≥ 300 万元
数据来源：销售负责人在当晚 20:00 前汇总意向书

指标：到场决策人比例
口径：到场人员中老板/采购负责人占比
目标值：≥ 70%
数据来源：签到表职务栏统计，签到组当晚汇总

指标：新经销商签约数
口径：此前无合作的新经销商签署意向书数量
目标值：≥ 15 家
数据来源：销售负责人对照经销商名录核对
```

**第 5 步对齐**：一页纸发给销售负责人、市场负责人、老板三方确认。后续预算向"促成签约"倾斜：政策宣讲环节加长、伴手礼降档、签约区布置升级——所有取舍回头看这页纸。

## 常见追问话术

目标拆解时用户经常答不上来，用选择题代替开放式追问：

- 定类型："活动结束那天晚上，你希望发生的最重要的事是什么？A 很多人知道了我们 B 很多人留了联系方式 C 很多人当场掏钱"
- 定人群："来的 100 个人里，你最在乎哪 20 个？他们是什么身份？"
- 定指标："如果只能用一个数字向老板汇报这次活动成没成，你选哪个数字？"
- 辨虚荣指标："到场 500 人但没人下单，算成功吗？"——用户说"不算"，虚荣指标现形。
- 辨模糊动词：用户说"提升品牌影响力"时追问"提升了你怎么知道？看到什么数字你会点头？"

## 目标说明书模板

```markdown
# 《XXX 活动》目标说明书（v1.0，待三方确认）

- 活动类型：销售促成型 / 品牌曝光型 / 获客转化型 / 关系维护型
- 核心目的（一句话）：____________
- 目标人群：谁来 / 为什么来 / 来了做什么
- 量化指标（3~5 个）：指标名 / 口径 / 目标值 / 数据来源 / 统计时间点
- 次要目的（不超过 2 个）：____________
- 确认人：______  ______  ______   日期：______
```

## 自检与反馈

**质检门**（输出前自查）：

- [ ] 活动类型已判定，且核心目的单选已完成
- [ ] 目标人群画像具体到"谁/为什么来/来了做什么"
- [ ] 3~5 个量化指标，每个都过了"可衡量/可归因/有数据来源"三问
- [ ] 每个指标写清了口径、目标值、数据来源与统计时间点
- [ ] 目标说明书已控制在一页纸内

**标准冒烟用例**：输入"给经销商办场新品订货会"，应输出：类型=销售促成型；核心目的=现场签约；指标含"现场签约额≥X 万元（口径：当天签署意向书）""到场经销商数""新品 SKU 平均订货量"；且每个指标带数据来源。

**一键反馈**：发现方法论缺口（如某种活动类型覆盖不到），以 `[QC] <一句话问题>` 为标题提交到 https://github.com/lhg-plugs/lhg-event-plan/issues，正文写清"场景 → 当前方法的不足 → 期望补充什么"。
